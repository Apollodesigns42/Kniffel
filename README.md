# 🎲 Kniffel

Das klassische Würfelspiel als Web-App – ohne Abhängigkeiten, läuft direkt im Browser, auf dem Handy auch installierbar und offline spielbar.

## Funktionen

- 1–6 Spieler reihum an einem Gerät
- Bis zu 3 Würfe pro Zug, Würfel per Antippen halten
- Spielblock mit Punktevorschau für jedes freie Feld, Streichen mit 0 Punkten
- Automatische Summen inkl. Bonus (35 Punkte ab 63 oben)
- Spielstand wird automatisch gespeichert und kann fortgesetzt werden
- Bestenliste (Top 10, lokal im Browser)
- Hell/Dunkel-Modus, Tastatursteuerung (Leertaste = würfeln, 1–5 = halten)

## Starten

`index.html` direkt im Browser öffnen – oder mit lokalem Server (für Offline-/Installations-Funktion):

```bash
npm start
```

## Tests

npm test
